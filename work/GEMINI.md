# GEMINI.md ベストプラクティス

本プロジェクトで gemini cli を安全かつ再現性高く使用するための最小ガイド。

## 目的
- 一貫した使い方: 同じフラグ・書式で結果を再現可能にする。
- セキュア運用: 機密を漏らさず、最小権限で利用する。
- 監査可能性: 入出力と意思決定を簡潔に記録する。

## セットアップ
- 要件: gemini cli（`gemini --version` で確認）、ネットワーク接続。
- インストールは公式 README を参照。
- 端末の既定ロケール/エンコーディングは UTF-8 を推奨。

## 認証
- 推奨: API キー方式（環境変数）。
  - `export GEMINI_API_KEY="<Google AI Studio の API キー>"`
- 代替: OAuth（CLI の案内に従いブラウザで承認）。
- キー管理: `.env` 等に保存し、VCS へコミットしない。CI はシークレットで注入。

## 基本コマンド
- 単発プロンプト: `gemini -p "要件を日本語で…"`
- モデル指定: `gemini -m gemini-1.5-flash -p "…"`
- 標準入力: `echo "…" | gemini`
- ファイル添付: `gemini -p "要約" -f path/to/spec.md`
- ストリーム: `gemini --stream -p "…"`
- 出力形式: `gemini --json -p "構造化で…"`
- システムプロンプト: `gemini --system "役割・制約" -p "質問"`

## プロンプト作法
- 目的を先に: 「何を出力するか」を1行で明示。
- 制約を列挙: 文字数/形式/禁止事項/依存前提などを箇条書きで。
- コンテキストは最小十分: 余分な原文は添付ファイル化し、本文は要約を渡す。
- 出力検証容易性: フォーマット（JSON/Markdown/箇条書き）を指定。
- 再現性: モデル名、温度、最大トークンを固定（例: `--temperature 0.2 --max-tokens 1024`）。
- 機密回避: 機密はダミーに置換し、実値は後工程で差し込む。

## セキュリティ
- 秘密情報の取り扱い
  - API キー/トークン/個人情報はプロンプトに含めない。
  - どうしても必要な場合は部分マスキングし、保存はしない。
- 依存外部リンクを盲信しない。実行前に人間レビュー。
- 生成コードのライセンス注意。出典要求や社内テンプレ優先。

## ロギング/記録
- 重要な実行は `codex/chat-YYYY-MM-DD.md` に要約を追記。
  - 記録項目: 目的/モデル/主要フラグ/入出力の要旨/意思決定。
- 生ログは保存しない（機密混入防止）。必要時のみ一時保管し速やかに削除。

## トラブルシューティング
- 認証エラー: `GEMINI_API_KEY` を再設定。OAuth は再ログイン。
- ネットワーク不可: プロキシ/ファイアウォールを確認。必要に応じ `--timeout` を延長。
- モデル未対応: `-m gemini-1.5-flash` など公開モデルに切替。
- 出力が冗長: 目的を短く、上限を `--max-tokens` で制限。
- 品質不安定: 温度を `--temperature 0.2` 付近に下げ、制約を明確化。
- 長文入力: 添付 `-f file` を活用し、本文は要約を渡す。

## ミニ例
- 仕様要約
  - `gemini -m gemini-1.5-flash -p "以下の仕様の要点を5点で: 出力はMarkdownの箇条書き" -f docs/spec.md`
- バグ調査プロンプト
  - `gemini --system "あなたはバグ調査の相棒。" -p "現象/期待/再現/ログを読み、原因仮説と次の一手を3つ" -f logs/error.txt`
- 設計レビュー
  - `gemini -p "方針A/Bを比較。評価基準: パフォーマンス/保守/安全。結論と根拠を短く" -f docs/design.md`
- JSON 生成
  - `gemini --json -p "この表をJSONに正規化（キーは英小文字スネークケース）" -f data/table.md`
- 要約＋アクション
  - `gemini -p "本文を5点要約し、担当/期限付きTODOを3件生成" -f notes/meeting.md`

## 運用ポリシー（本リポジトリ）
- gemini cli の質問は公式 README を参照し、回答はチートシート的に短く。
- 実行例は `gemini -p "…"` 形式を使用。
- 重要な出力は `codex/chat-YYYY-MM-DD.md` へ記録（機微なし）。
